# 山野之间 · 国内名山徒步旅行

一个纯前端（HTML / CSS / JavaScript，无框架、无后端）的国内名山徒步旅行主题网站。

## 功能

- **首页**：网站标题、简介、响应式导航栏、Hero 横幅、精选目的地推荐、页脚，适配桌面与移动端
- **目的地卡片**：可复用组件，展示黄山、泰山、华山、峨眉山、武功山、三清山、长白山、衡山 8 座名山的省份、海拔、徒步难度、最佳季节、简介与图片
- **搜索栏**：按山名 / 省份 / 简介实时过滤
- **配色**：自然山野风格（松林绿 / 苔藓绿 / 云雾白 / 大地棕）

## 目录结构

```
mountain-trek/
├── index.html       # 首页骨架
├── css/style.css    # 样式
├── images/          # 名山图片
└── js/
    ├── data.js      # 模拟数据
    └── app.js       # 渲染与交互逻辑
```
